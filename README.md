# Personal Jarvish

A lightweight personal command-line assistant you can run locally.

## Features
- Personal setup (your name, assistant name, daily goal)
- Quick status summary (date, time, goal)
- Motivation prompts
- Goal updates on demand
- Profile persistence in `~/.jarvish_profile.json`

## Run
```bash
python3 jarvish.py
```

## Commands
- `help`
- `status`
- `motivate`
- `goal`
- `setup`
- `quit`
